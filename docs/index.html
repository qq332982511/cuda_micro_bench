SM_120 Microarchitecture Measured

Cycle-level characterization of an NVIDIA Blackwell GPU, synthesized from inline-PTX microbenchmarks.

View source on GitHub ↗

Reviewed on RTX 5060 Ti (CC 12.0). Kernel costs include loop/address overhead; nanoseconds derived from the device clock attribute are nominal estimates. External GB202 reference values are not pass/fail thresholds for this GPU. See methodology review.

Microarchitecture Diagram

Simplified SM block diagram and memory hierarchy, annotated with measured latency/throughput values. FP32 and INT32 share execution resources on RTX Blackwell. Boxes are illustrative; rates are warp PTX operations, with event-based rates normalized using the nominal clock.

Topology

Device limits and on-chip resources reported by the CUDA driver and measured microbenchmarks.

Dependency Chains & ILP

FFMA and IMAD dependency/ILP sweeps include loop overhead. Saturation is an observed chain count; it does not measure physical pipeline stages or I-buffer depth.

Co-Issue

Wall-clock cycle measurement of FMA-only, IMAD-only, and interleaved FMA+IMAD dependent chains. The overlap ratio measures latency hiding. RTX Blackwell shares FP32/INT32 execution resources; overlap does not prove simultaneous issue.

Tensor Memory Accelerator (TMA)

Latency of a 1D cp.async.bulk.tensor global-to-shared load (16-byte tile) measured with an mbarrier, and global-to-shared bulk-copy bandwidth via cuda::device::memcpy_async_tx.

TMA vs LSU (load/store path)

Read-only streaming bandwidth is compared with TMA global-to-shared bulk-copy bandwidth. TMA uses different transfer sizes and occupancy. The hot 16-byte TMA issue/wait cost is shown separately; it is not a DRAM miss latency.
